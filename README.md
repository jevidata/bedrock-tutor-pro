# 🤖 Bedrock Tutor Pro - IA Académica

Este proyecto es un **Tutor Inteligente** especializado en IA y Data Science. Utiliza **Amazon Bedrock** y agentes con **Knowledge Bases (RAG)** para responder preguntas basadas en documentación oficial del IES (Reales Decretos, temarios y metodologías).

## 🚀 Características
- **Búsqueda Semántica**: Extrae información precisa de documentos PDF.
- **Respuestas Exhaustivas**: Configurado para no omitir detalles técnicos ni administrativos.
- **Arquitectura Moderna**: Backend con **FastAPI** y Frontend minimalista con **JavaScript/CSS**.
- **Sesiones Únicas**: Cada consulta genera una sesión nueva para garantizar respuestas frescas.

## 🛠️ Tecnologías
- **Amazon Nova Pro** (Modelo de lenguaje de última generación)
- **Amazon Bedrock Knowledge Bases** (RAG para documentos oficiales)
- **Python 3** (FastAPI)
- **Boto3** (SDK de AWS)
- **HTML/CSS/JS**

## 📂 Estructura del Proyecto
- `main.py`: Lógica del servidor y conexión con el Agente de Bedrock.
- `frontend/`: Interfaz de usuario del chat.
- `docs/`: Documentación oficial utilizada para entrenar la KB.
